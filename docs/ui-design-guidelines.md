# NarratoAI C 端 Web UI 设计规范

生成日期：2026-07-03  
依据来源：`docs/c-user-web-prototype/产品规格与页面流程.md` 中 D01-D40 对应的原型图  
适用范围：Figma 设计稿、后续 Web 实现、设计走查与视觉还原验收。

> 说明：本文档以 D01-D40 原型图为视觉依据，不以 `docs/c-user-web-prototype/src/App.jsx` 和 `styles.css` 为依据。那份代码原型已废弃，不能作为本规范的设计来源。

## 1. 原型图总体风格

当前 D01-D40 原型图是一套偏“工具台 / 工作流”的 C 端 Web 产品设计，而不是营销型落地页。

主要视觉特征：

- 大面积白底，浅灰分隔，整体干净克制。
- 顶部固定主导航，品牌在左，用户入口在右。
- 红色作为品牌色和主操作色。
- 绿色用于已完成步骤。
- 红色也用于当前步骤、失败态、主按钮和重要提醒。
- 页面主体以表单、表格、步骤条、任务卡片为主。
- 页面文案短，偏操作说明，不做大段营销表达。
- 创作流程页强调“当前步骤 -> 可编辑内容 -> 下一步确认”。
- 配置中心采用左侧二级导航 + 右侧表单内容。

## 2. 设计定位

NarratoAI C 端 Web 面向想做短视频账号的普通用户，核心不是展示产品能力，而是帮助用户完成一次完整创作。

设计关键词：

- 清楚：用户知道当前在哪一步。
- 可控：自动生成也能查看进度，精细模式可逐步确认。
- 可靠：失败态、空状态、配置缺失都有承接。
- 轻量：页面只呈现当前任务需要的信息。
- 工具化：上传、编辑、表格、配置、导出是核心界面语言。

## 3. 页面骨架规范

### 3.1 全局顶部导航

原型图特征：

- 顶部白色导航栏贯穿所有页面。
- 左侧是 NarratoAI 品牌标识。
- 中间是主导航：首页、我的作品、素材库、配置中心、帮助。
- 当前页使用红色文字或红色下划线强调。
- 右侧是用户头像、用户名和下拉入口。

规范：

| 元素 | 规范 |
| --- | --- |
| 高度 | 56-64px |
| 背景 | 白色 |
| 分隔 | 底部 1px 浅灰线 |
| 当前导航 | 红色文字 + 红色短下划线 |
| 品牌区 | 图标 + NarratoAI 文本 |
| 用户区 | 头像、用户名、下拉箭头 |

### 3.2 页面内容区

原型图中的内容区普遍采用：

- 顶部面包屑。
- 页面标题。
- 副标题/状态标签。
- 主内容卡片或表格。
- 底部操作区。

规范：

| 区域 | 规范 |
| --- | --- |
| 页面边距 | 左右 40-56px |
| 内容最大宽度 | 以 1440 桌面宽度为主要设计画布 |
| 页面标题 | 24-32px，黑色，字重 600-700 |
| 辅助说明 | 12-14px，灰色 |
| 主内容区 | 白底卡片或直接白底表格 |
| 页面背景 | `#f7f8fa` 或接近白色的浅灰 |

### 3.3 面包屑

用于上传页、生成页、精细模式页、作品详情页。

规范：

- 位于页面标题上方。
- 字号 12px。
- 使用浅灰文字。
- 当前页文字略深。
- 不抢主视觉。

## 5. 字体规范

原型图使用的是典型中文 Web 工具产品字体表现，建议 Figma 和后续实现统一为系统中文字体。

字体栈：

```css
font-family: "PingFang SC", "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif;
```

| 场景 | 字号 | 字重 | 用途 |
| --- | --- | --- | --- |
| 页面主标题 | 24-32px | 600-700 | 上传页、生成页、结果页标题 |
| 页面副标题 | 13-14px | 400 | 页面说明、任务描述 |
| 区块标题 | 16-18px | 600 | 卡片标题、表单分组标题 |
| 表格表头 | 12-13px | 500-600 | 列名 |
| 表格正文 | 12-14px | 400 | 列表和脚本内容 |
| 表单标签 | 13-14px | 500 | 输入项名称 |
| 按钮文字 | 14px | 500-600 | 主按钮、次按钮 |
| 状态标签 | 12px | 500-600 | 生成中、已完成、失败 |
| 步骤数字 | 13-14px | 600 | 步骤圆点 |

注意：

- 不使用超大营销标题。
- 工具页标题控制在 24-32px。
- 表格和配置页要优先保证信息密度。
- 文本不要使用负字距。

## 7. 圆角、边框和阴影

原型图整体圆角克制，主要靠细边框和浅底区分层级。

| 元素 | 圆角 | 边框/阴影 |
| --- | --- | --- |
| 普通按钮 | 4-6px | 1px 细边框 |
| 主内容卡片 | 8-12px | 1px `border-default` |
| 上传区域 | 8-12px | 1px dashed `border-default` |
| 状态标签 | 999px 或 4px | 浅底色，无强阴影 |
| 表格容器 | 8px | 1px 浅边框 |
| 弹窗 | 12px | 轻阴影 |
| 视频预览 | 4-8px | 深色背景 |

阴影使用原则：

- 原型图中阴影很少，不要做强卡片阴影。
- 仅弹窗、下拉菜单、浮层使用轻阴影。
- 主页面卡片优先用边框和浅灰背景分层。

## 8. 按钮规范

### 8.1 主按钮

原型图中主按钮多为红底白字，常见于：

- 下一步。
- 确认进入下一步。
- 开始生成视频。
- 下载视频。
- 上传素材。
- 重试任务。

规范：

| 属性 | 规范 |
| --- | --- |
| 背景 | `brand-red` |
| 文字 | 白色 |
| 高度 | 36-40px |
| 圆角 | 4-6px |
| 字号 | 14px |
| 宽度 | 按内容或固定主操作宽度 |

### 8.2 次按钮

用于返回、取消、查看、重新选择、测试连接。

规范：

- 白底。
- 浅灰边框。
- 深灰文字。
- hover 可使用浅灰底。

### 8.3 危险按钮

用于删除、取消任务、清空。

规范：

- 默认白底红字红边。
- 确认弹窗中的最终危险操作可使用红底白字。
- 危险操作必须配合二次确认或明确提示。

### 8.4 按钮布局

原型图中精细模式底部操作常见结构：

```text
上一页        确认结果，下一步
```

规范：

- 主按钮放右侧或底部中右。
- 返回/上一步为次按钮。
- 一个页面只保留一个最高优先级主按钮。

## 9. 状态标签规范

状态标签贯穿作品列表、生成页、结果页、配置页。

| 状态 | 颜色 | 使用场景 |
| --- | --- | --- |
| 生成中 | 蓝色或红色浅底 | 任务运行中 |
| 待确认 | 橙色 | 精细模式等待用户确认 |
| 已完成 | 绿色 | 任务完成、步骤完成 |
| 失败 | 红色 | 任务失败、字段错误 |
| 已取消 | 灰色/橙色 | 用户取消或任务终止 |
| 可用/正常 | 绿色 | 配置测试通过、素材正常 |

标签形态：

- 高度 22-26px。
- 字号 12px。
- 圆角 4px 或胶囊。
- 浅色背景 + 深色文字。

## 10. 步骤条规范

步骤条是原型图最核心的流程组件，出现在自动模式、精细模式、作品详情、失败详情。

### 10.1 基础形态

- 横向步骤条。
- 每个步骤由圆点、步骤名、状态文字组成。
- 步骤之间使用细线连接。
- 已完成为绿色圆点和绿色连接线。
- 当前步骤为红色圆点。
- 未开始为灰色圆点。
- 失败步骤为红色错误标识。

### 10.2 自动模式步骤条

展示内容：

- 字幕处理 / 剧情理解 / 生成脚本 / 生成配音 / 合成视频。
- 当前进行中步骤。
- 已用时间。
- 预计剩余。
- 预计完成时间。
- 返回我的作品。
- 取消任务。

### 10.3 精细模式步骤条

展示内容：

- 字幕确认。
- 剧情理解或画面分析。
- 解说文案。
- 剪辑脚本。
- 配音字幕。
- 合成导出。

规范：

- 步骤条位于标题下方、主内容上方。
- 当前步骤红色。
- 已确认步骤绿色。
- 未开始步骤灰色。
- 失败时在对应步骤显示红色失败节点。

## 11. 上传页规范

上传页包括 D02-D05。

### 11.1 页面结构

通用结构：

- 面包屑。
- 页面标题。
- 上传素材区。
- 可选字幕/脚本/主题输入。
- 模式选择。
- 底部操作：返回、下一步。

### 11.2 上传区

原型图特征：

- 上传区域为白底卡片。
- 中心放上传图标和上传说明。
- 多视频场景左侧展示视频列表和缩略图。
- 可选字幕位于右侧或旁侧卡片。

规范：

| 状态 | 展示 |
| --- | --- |
| 未上传 | 上传图标、格式说明、点击上传 |
| 已上传 | 文件名、时长、大小、缩略图、删除 |
| 上传中 | 进度条、取消 |
| 上传失败 | 红色提示、失败原因、重新上传 |

### 11.3 模式选择

自动模式和精细模式使用卡片式选择。

规范：

- 两个选项并排。
- 当前选中项使用红色边框、浅红底或红色角标。
- 每个选项包含标题和一句短说明。

## 12. 精细模式页面规范

精细模式页面包括 D12-D26，是设计稿还原的重点。

### 12.1 通用结构

```text
顶部导航
面包屑
页面标题 + 任务信息/状态标签
横向步骤条
主内容区
底部操作区
```

### 12.2 主内容区布局

根据原型图，精细模式主内容常用两栏：

- 左侧/中间：表格、文本、字幕、脚本等主要编辑内容。
- 右侧：统计、摘要、操作、预览或参数。

规范：

- 主内容优先白底表格或白底编辑区。
- 右侧摘要卡片宽度控制在 220-320px。
- 底部固定“上一页 / 确认结果，下一步”。

### 12.3 字幕确认

必须展示：

- 字幕文件来源。
- 字幕时间轴列表。
- 每条字幕时间段、内容、状态。
- 编辑、删除、校准、重新识别入口。
- 确认进入下一步。

### 12.4 剧情理解 / 画面分析 / 片段分析

必须展示：

- 模型生成结果。
- 可编辑区域或表格。
- 重新生成。
- 摘要统计。
- 确认进入下一步。

### 12.5 解说文案

必须展示：

- 分段文案列表。
- 每段时间或对应素材。
- 字数统计。
- 语气/风格参数。
- 编辑、重写单段、重新生成。

### 12.6 剪辑脚本

必须展示：

- 片段序号。
- 视频来源。
- 时间段。
- 画面内容。
- 解说内容。
- OST 类型。
- 操作按钮。

OST 视觉建议：

| OST | 含义 | 视觉 |
| --- | --- | --- |
| `OST=0` | 解说配音 | 红色浅底标签 |
| `OST=1` | 原片原声 | 绿色或蓝色浅底标签 |
| `OST=2` | 解说 + 原声 | 橙色浅底标签 |

### 12.7 配音字幕

必须展示：

- 配音引擎或音色选择。
- 分段配音列表。
- 字幕样式设置。
- 字幕预览。
- 背景音乐和音量。
- 试听或播放控制。

### 12.8 合成导出

必须展示：

- 已确认内容清单。
- 导出格式、比例、分辨率。
- 字幕、配音、背景音乐状态。
- 开始合成视频主按钮。

## 16. 配置中心规范

- 页面标题“配置中心”。

- 测试连接放在字段右侧或分组底部。
- 保存按钮固定在页面底部或表单末尾。
- 成功/失败结果用状态标签或轻提示。

### 16.3 预览区

字幕设置页需要视频/字幕预览。

规范：

- 预览区放右侧。
- 使用真实视频封面或示例画面。
- 显示字幕样式变化。
- 不要让预览区压缩主要配置表单。

## 17. 表格规范

原型图中表格是高频组件，出现在作品、素材、字幕、脚本、片段分析、配置列表。

规范：

| 元素 | 规范 |
| --- | --- |
| 表头 | 浅灰底或白底，12-13px，弱化 |
| 行高 | 44-56px |
| 分隔 | 1px 浅灰线 |
| hover | 浅灰背景 |
| 当前/选中 | 浅红底或浅蓝底 |
| 操作列 | 放右侧，使用文字按钮或小图标 |
| 状态列 | 使用彩色标签 |

表格不应过度装饰；信息密度优先。

## 18. 空状态与失败页规范

### 18.1 空状态

空状态包括 D39、D40。

规范：

- 居中图标。
- 标题简短，如“暂无作品”“暂无视频素材”。
- 一句说明。
- 主按钮：新建作品 / 上传素材。
- 次按钮：查看示例 / 返回首页。
- 空状态容器使用虚线边框或浅灰背景。

### 18.2 失败页

失败页包括 D37、D38。

规范：

- 页面标题“任务失败”。
- 顶部红色错误提示卡片。
- 显示失败阶段。
- 显示失败原因和错误码。
- 步骤条中失败节点标红。
- 保留已完成内容。
- 提供重试、重新上传素材、返回我的作品。
- 技术细节可以折叠，不直接大面积暴露堆栈。

## 19. 图标规范

原型图中图标使用轻量线性或填充图标，主要用于：

- 上传。
- 视频。
- 字幕。
- 音乐。
- 配置。
- 生成步骤。
- 成功/失败状态。
- 操作按钮。

规范：

- 图标尺寸 14-20px。
- 主状态图标可到 28-40px。
- 普通图标使用灰色。
- 当前/主操作使用红色。
- 完成使用绿色。
- 失败使用红色圆形错误图标。

## 20. 响应式规范

当前原型图以桌面 Web 为主，Figma 第一版应优先保证桌面端。

建议断点：

| 断点 | 处理 |
| --- | --- |
| 1440px | 主设计画布 |
| 1200px | 减少左右边距，表格保持横向 |
| 960px | 两栏变单栏，右侧摘要移到主内容下方 |
| 768px | 顶部导航收纳，步骤条可横向滚动 |
| 390px | 移动端单栏，按钮通栏，表格改卡片 |

移动端重点：

- 上传页和结果页优先适配。
- 精细模式复杂表格可先提供横向滚动方案。
- 配置中心左侧导航变顶部 Tab。
- 主按钮固定在页面底部或内容末尾。

## 22. Figma 还原验收

生成或调整 Figma 时，按以下清单验收：

- 是否以 D01-D40 原型图为主要视觉依据。
- 是否保持白底、浅灰线、红色主操作的克制风格。
- 是否没有套用废弃代码原型里的大 hero、强渐变、大卡片营销风。
- 顶部导航是否与原型图一致。
- 上传页是否使用原型图中的上传卡片和模式选择。
- 自动生成页是否保留横向步骤条和任务时间信息。
- 精细模式是否保留步骤条、表格/编辑区、底部确认按钮。
- 配置中心是否使用左侧二级导航 + 右侧表单。
- 素材库是否使用 Tab + 搜索 + 列表/卡片。
- 失败页是否使用红色错误卡片和失败步骤条。
- 空状态是否居中、轻量、带主操作。
- OST=0/1/2 是否在剪辑脚本表中可辨识。
- 主要按钮是否只有一个最高优先级。
- 页面是否偏工具化，而不是营销介绍页。
