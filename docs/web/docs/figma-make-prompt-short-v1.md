# Figma Make 精简提示词 v1

请为一个 AI 自媒体视频出片工具网站生成高保真 UI 设计稿，产品暂名「Narrato AI / AI 出片工作台」。

产品面向不会剪辑、不会写解说词、缺乏导演思维的自媒体小白用户。用户上传视频后，AI 帮助完成短剧解说、视频翻译、短剧混剪等创作流程，最终生成可发布的视频。

## 核心功能

首版包含 3 个工具：

1. **短剧解说**：主推功能。用户上传一集或多集短剧，AI 识别高光片段，生成解说文案、配音、字幕、BGM，并合成解说视频。
2. **视频翻译**：用户上传视频或字幕，选择源语言和目标语言，AI 翻译字幕、重新配音、压制字幕并导出视频。
3. **短剧混剪**：AI 自动找高光片段，保留原声并添加 BGM，生成节奏更紧凑的混剪视频。

首版不是复杂剪辑软件，而是「专业但小白可用」的 AI 工作台。每一步都应有默认推荐，让用户可以直接继续。

## 需要设计的主要页面

请优先生成桌面端设计稿，并兼顾移动端适配思路：

- 官网首页
- 工作台概览页
- 新建创作页
- 短剧解说编辑页
- 视频翻译编辑页
- 短剧混剪编辑页
- 我的项目页
- 项目详情 / 结果页
- 价格页

## 首页要求

首页用于转化用户，首屏要让用户 5 秒内理解产品价值。

首页主标题建议：

> 专为自媒体小白打造的 AI 出片工作台

副标题建议：

> 上传素材，AI 自动完成剪辑、文案、配音、字幕与合成。短剧解说、视频翻译、智能混剪，一个工作台搞定。

主按钮：

> 开始创作

首页需要展示三大工具卡片、Demo 案例、工作台专业能力预览和价格入口。

## 工作台要求

工作台要有暗色专业剪辑台质感，但不要复杂到像剪映。

基础结构：

- 左侧导航：概览、我的项目、短剧解说、视频翻译、短剧混剪、价格 / 会员、设置
- 顶部栏：创作点余额、充值按钮、用户头像
- 主区域：新建创作入口、案例、最近项目

编辑页布局建议：

- 中间最大区域放视频预览
- 左侧放素材 / AI 推荐片段 / 字幕列表
- 底部放简化时间线
- 右侧放当前步骤参数
- 顶部放步骤条、保存状态、导出按钮

短剧解说步骤：上传素材 → 设置参数 → AI 分析 → 编辑片段 → 编辑文案 → 配音字幕 → 预览导出。

## 视觉风格参考

参考图：

https://gamecdn.beiyinapp.com/temp/20267131783905152610.png

请提取其视觉感觉，而不是照抄内容：

- 蓝紫粉渐变
- 高饱和、年轻化、科技感
- 玻璃拟态卡片
- 浮动卡片和层叠界面
- 电竞 / 游戏宣传页式的冲击力
- 暗色背景 + 霓虹高光
- 首页更酷炫，工作台更专业

避免普通白底 SaaS 风格，避免低保真线框图，避免卡通化。

## 关键 UX 细节

- 生成前展示预计消耗的「创作点」
- 真实生成需要登录和创作点
- 任务有状态：草稿、生成中、已完成、失败
- 失败时展示失败原因和步骤日志
- 短剧解说是主推，视觉权重最高
- 不承诺“保证爆款”，表达为“AI 识别高光”“生成可编辑草稿”“快速生成可发布视频”

请输出高保真、现代、酷炫、可信的 AI 视频创作产品设计稿。
