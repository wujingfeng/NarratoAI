# AI 自媒体视频出片工具网站 MVP 取舍与验收标准

> 日期：2026-07-09  
> 原则：上线 2 周内验证价值  
> 上游文档：`docs/web/docs/ai-video-tools-requirements-v1.md`

---

## 1. 取舍原则

第一版不追求“功能完整”，只验证一个核心问题：

> 用户看到案例和工作台后，是否愿意付费上传素材，并接受 AI 生成的可发布成片。

因此第一版只保留能直接影响以下指标的功能：

1. 用户是否愿意注册 / 登录
2. 用户是否愿意付费购买创作点
3. 用户是否愿意上传真实素材
4. 用户是否能完成一次生成任务
5. 用户是否愿意下载 / 导出结果
6. 用户是否认为生成结果“能直接发”或“值得继续调”

第一版不验证：

- 是否能做成专业剪辑软件
- 是否能覆盖所有视频创作场景
- 是否能批量生产矩阵号
- 是否能自动保证爆款
- 是否能支持所有语言、所有字幕样式、所有配音风格

---

## 2. 必须做的核心功能

### 2.1 首页转化闭环

必须做，因为这是 KOL 和 SEO 流量进入后的第一转化点。

核心范围：

- 首页首屏
- 主 CTA「开始创作」
- 三个 Demo 展示：短剧解说、视频翻译、短剧混剪
- 工作台专业能力露出
- 价格菜单入口
- 登录 / 进入工作台入口

验收标准：

- 用户进入首页 5 秒内能明白这是 AI 视频出片工作台
- 首屏能看到明确 CTA「开始创作」
- 首页能清楚表达三个工具：短剧解说、视频翻译、短剧混剪
- Demo 顺序为：短剧解说 > 视频翻译 > 短剧混剪
- 首页不直接展示价格套餐，但顶部或导航中有价格入口
- 移动端首页不出现明显错位、横向滚动或无法点击 CTA 的问题

---

### 2.2 登录与付费前置闭环

必须做，因为第一版真实生成必须付费，2 周内要验证付费意愿。

核心范围：

- 登录 / 注册
- 创建任务前登录拦截
- 创作点余额展示
- 价格页
- 积分包 + 会员订阅展示
- 创建任务时创作点不足弹窗
- 工作台固定价格 / 会员入口
- 顶部限时套餐营销条

验收标准：

- 未登录用户可浏览首页和案例
- 用户上传素材后、生成前必须登录
- 用户能在工作台看到创作点余额
- 用户能进入价格页查看积分包和会员订阅
- 创作点不足时，创建任务流程被拦截并弹出购买引导
- 用户购买后，除固定菜单入口外，顶部营销条等非必要营销不再展示
- 购买后创作点或权益状态能影响创建任务判断

---

### 2.3 项目与任务闭环

必须做，因为用户生成过程可能耗时，必须能回到项目继续查看状态。

核心范围：

- 一个生成任务 = 一个项目
- 项目区分任务类型：短剧解说 / 视频翻译 / 短剧混剪
- 我的项目列表
- 项目状态
- 项目详情 / 编辑入口
- 任务步骤状态
- 任务日志
- 失败原因展示

验收标准：

- 创建任一工具任务后，会生成一条项目记录
- 项目列表至少显示：项目名称、状态、创建时间、缩略图、操作按钮
- 项目类型在列表或详情中可识别
- 用户刷新页面后仍能看到项目
- 任务失败时能看到失败原因和步骤日志
- 第一版不要求通知，但用户进入项目详情时必须能看到当前处理状态

---

### 2.4 短剧解说核心闭环

必须做，而且是第一版最重要的验证功能。

核心范围：

- 上传一集或多集短剧
- 默认按上传顺序，允许拖动排序
- 设置解说风格
- 视频比例、配音角色、字幕样式提供默认值并可修改
- AI 分析素材
- AI 推荐片段
- 片段起止时间编辑
- 合并时间线内片段重叠校验
- 生成解说文案
- 用户修改解说文案
- 配音、字幕、BGM、合成
- 导出成片

验收标准：

- 用户能上传多个视频并调整顺序
- 默认视频比例跟随首个上传视频
- 用户只选择解说风格，也可以继续下一步
- 系统能产出 AI 推荐片段列表
- 用户能编辑片段起止时间
- 同一合并时间线内重叠片段不允许保存或继续生成
- 系统能生成可编辑解说文案
- 用户能修改文案并进入配音字幕流程
- 系统能合成包含原片片段、旁白配音、字幕、BGM 的视频
- 生成结果页能预览和导出
- 核心质量最低线：前 3 秒有钩子、无明显废片段、解说不明显尴尬、节奏不明显拖沓

---

### 2.5 视频翻译最小闭环

必须做，但范围必须收窄；它是次推功能，用来验证“工具集合”价值，不做成全能翻译平台。

核心范围：

- 上传视频
- 可选上传字幕
- 源语言 / 目标语言选择
- 源语言默认中文，目标语言默认英文
- 无字幕时调用 ASR
- 翻译字幕
- 用户修改字幕内容
- 选择配音角色
- 选择字幕样式
- 重新配音
- 翻译字幕压制到视频
- 导出成片

验收标准：

- 用户能选择源语言和目标语言
- 不上传字幕时能进入 ASR 识别流程
- 上传字幕时优先使用字幕内容
- 系统能生成可编辑的翻译字幕
- 用户能修改翻译字幕
- 系统必须生成目标语言 AI 配音
- 翻译字幕能压制到视频画面上
- 自动检测不到原字幕时，翻译字幕默认放底部
- 输出视频能预览和导出

---

### 2.6 短剧混剪最小闭环

必须做，但只能保留“高光片段 + 原声 + BGM”的简单模型。

核心范围：

- 上传一集或多集短剧
- AI 推荐高光片段
- 用户调整片段起止时间
- 用户可重新生成一组片段
- 保留原声
- 添加 BGM
- 合成导出

验收标准：

- 用户能上传一个或多个视频
- 系统能生成高光片段列表
- 用户能调整片段起止时间
- 用户能触发重新生成片段
- 片段之间不允许时间重叠
- 输出视频保留原声并叠加 BGM
- 第一版不出现字幕、旁白、配音配置
- 输出视频能预览和导出

---

### 2.7 统一结果页 / 预览导出

必须做，因为“能不能直接发”是核心价值判断。

核心范围：

- 视频预览
- 导出 / 下载
- 任务类型展示
- 消耗创作点展示
- 返回编辑
- 失败状态展示

验收标准：

- 三个工具生成完成后都进入视觉统一的结果页
- 结果页能播放预览视频
- 用户能下载或导出视频
- 结果页展示项目名称、工具类型、生成状态
- 如果生成失败，结果页或详情页展示失败原因和步骤日志

---

## 3. 可以延后的增强功能

以下功能有价值，但不影响 2 周内验证付费和生成闭环，应延后。

### 3.1 真正一键模式

延后原因：第一版已经通过默认值 + AI 推荐降低门槛，真正一键模式可以等验证出用户愿意生成后再做。

包括：

- 上传后自动分析、自动剪辑、自动文案、自动配音、自动导出
- 用户只在结果页修改或重新生成

### 3.2 完整素材库

延后原因：第一版按任务上传即可，复用素材不是首要验证点。

包括：

- 素材长期保存
- 素材标签
- 素材复用
- 素材文件夹

### 3.3 通知系统

延后原因：第一期用户主动查看任务即可。

包括：

- 站内通知
- 邮件通知
- 短信通知
- 生成完成提醒

### 3.4 更复杂的会员权益体系

延后原因：第一版只要能完成付费验证，不要过早设计复杂权益。

包括：

- 多会员等级
- 权益叠加
- 团队席位
- 专属通道
- 复杂折扣券

### 3.5 大量配音角色和字幕模板

延后原因：第一版只需要提供足够默认选择，验证用户是否愿意生成。

建议第一版只保留少量高质量选项。

### 3.6 移动端完整剪辑体验

延后原因：移动端首页必须好，但复杂编辑流程在手机上做完整成本高、验证价值低。

第一版移动端只做：

- 首页适配
- 工作台基础查看
- 简单步骤可用

### 3.7 SEO 内容矩阵

延后原因：SEO 是长期增长，不是第一版核心产品闭环。

可以先做基础 SEO，不做大规模内容站。

### 3.8 自动标题、简介、标签、封面

延后原因：有利于发布，但不是第一版验证“AI 出片”必须项。

### 3.9 项目复制、版本管理、协作

延后原因：第一版用户还没验证，复杂项目管理暂缓。

## 4. 暂时不要做的伪需求

以下功能看起来高级，但会稀释 MVP、拉长周期，且不能直接验证 2 周内价值。

### 4.1 做成剪映级时间线编辑器

不要做。

原因：用户目标是省事，不是再学一个剪辑软件。第一版只需要片段起止时间、排序、重叠校验。

### 4.2 “自动保证爆款”

不要做。

原因：不可承诺，且无法用两周验证。可以说“高光识别”“爆点结构”，不要承诺爆款。

### 4.3 支持所有视频类型

不要做。

第一版优先：短剧素材、自媒体短视频素材。不要扩展到课程、直播、访谈、长电影、会议录像等全场景。

### 4.4 支持所有语言和复杂本地化

不要做。

第一版以中文源语言、英文目标语言为默认，语言列表可扩展，但不要承诺全球化翻译平台。

### 4.5 完美去除原视频硬字幕

不要做。

第一版只提供遮罩 / 模糊选项或字幕避让。硬字幕完美移除成本高，且容易翻车。

### 4.6 过度追求首页炫酷动效

不要做。

首页要高级，但不能为了动效牺牲加载速度、移动端体验和 CTA 转化。

### 4.7 复杂创作者社区 / 模板市场

不要做。

社区、模板市场、案例广场都不是首版验证点。

### 4.8 批量矩阵号生产

不要做。

第一版先验证单个用户单次生成是否愿意付费，不要提前做批量账号、批量任务、矩阵管理。

### 4.9 高级 BGM 曲库和版权管理

不要做。

第一版提供少量默认 BGM 或用户上传 BGM 即可。

## 6. 每个功能的验收标准汇总

| 功能 | 验收标准 |
|---|---|
| 首页首屏 | 5 秒内能看懂产品用途；CTA 明显；移动端可点击 |
| Demo 展示 | 按短剧解说、视频翻译、短剧混剪顺序展示；能体现上传到成片过程 |
| 价格入口 | 首页不直接展示套餐，但导航有价格入口；价格页可访问 |
| 登录拦截 | 上传后生成前触发登录；登录后能回到原流程 |
| 创作点校验 | 生成前能判断余额；不足时弹购买引导 |
| 项目创建 | 任一工具创建任务后生成项目记录 |
| 项目列表 | 显示项目名称、状态、创建时间、缩略图、操作按钮 |
| 任务日志 | 用户查看项目时能看到步骤状态和日志 |
| 失败展示 | 失败时展示失败原因和步骤状态 |
| 短剧解说上传 | 支持多视频；默认上传顺序；可拖动排序 |
| 短剧解说参数 | 只选解说风格也能继续；比例、配音、字幕有默认值 |
| 短剧解说片段 | 可编辑起止时间；重叠片段不能继续 |
| 短剧解说文案 | AI 生成文案可编辑；保存后用于配音 |
| 短剧解说导出 | 输出包含画面片段、解说配音、字幕、BGM |
| 视频翻译语言 | 源语言默认中文，目标语言默认英文，可修改 |
| 视频翻译字幕 | 可上传字幕；无字幕走 ASR；翻译结果可编辑 |
| 视频翻译配音 | 必须生成目标语言配音 |
| 视频翻译导出 | 输出包含翻译字幕和目标语言配音 |
| 短剧混剪片段 | AI 推荐高光片段；可调整时间；可重新生成片段 |
| 短剧混剪音频 | 输出保留原声并添加 BGM |
| 结果页 | 三个工具结果页视觉统一；可预览和导出 |
| 移动端首页 | 无明显错位；CTA、导航、Demo 可正常浏览 |
| 工作台基础移动端 | 可查看项目、状态和结果；复杂编辑可半适配 |

## 7. 2 周验证建议

上线后 2 周重点看以下数据：

1. 首页访问到点击「开始创作」转化率
2. 点击开始创作到上传素材转化率
3. 上传素材到付费转化率
4. 付费后创建任务成功率
5. 任务生成成功率
6. 生成后导出率
7. 用户是否二次创建任务
8. 用户反馈中是否出现“能直接发”“比自己剪快”“愿意继续用”

如果两周内出现以下信号，说明值得继续：

- 有用户愿意为真实生成付费
- 有用户完成导出
- 有用户二次创建项目
- 用户主要抱怨集中在质量优化，而不是“不知道这是干嘛的”或“完全不值钱”

如果两周内出现以下信号，需要重新定位：

- 首页点击率很低：说明定位 / 视觉 / 文案没打动
- 上传后不付费：说明价格、信任或案例不足
- 付费后不导出：说明生成质量或等待体验不达标
- 用户只看示例不上传：说明目标用户素材获取或信任问题较大

## 8. 第一版优先级结论

### P0：必须上线

- 首页转化闭环
- 登录 / 付费 / 创作点闭环
- 项目 / 任务 / 日志闭环
- 短剧解说完整生成闭环
- 视频翻译最小生成闭环
- 短剧混剪最小生成闭环
- 结果预览与导出
