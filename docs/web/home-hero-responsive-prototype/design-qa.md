## 迭代历史

### Pass 1

- **P1**：工作台整体过高、偏右，并出现参考图中没有的额外标题，破坏桌面叠压构图。
- **P2**：透视网格、Demo teaser 边界、品牌 logo、视频中心播放控件和波形细节与参考图存在明显差距。
- **处理**：收紧工作台尺寸和定位，移除额外标题；校正网格透视、Demo 露出高度、品牌标识比例、播放控件和 DOM 波形视觉。

### Pass 2

- **P2**：桌面工作台 bounding box、外壳比例、内部信息密度以及 Hero Copy 对齐仍需精调。
- **处理**：继续校准桌面工作台宽高、透视旋转、内容网格密度、左侧标题与 CTA 的垂直节奏。

### Pass 3

- 桌面同视口复验后，工作台实测 `x=497.0, y=96.7, w=971.9, h=726.2`；视觉源近似 `x=497, y=95, w=971, h=735`，位置和占比达到可接受匹配。
- 响应式复验发现 1024px 宽度仍存在 **P1** 文案与工作台重叠。
- **处理**：将堆叠 breakpoint 调整至 `<=1100px`，随后重新检查 1024 × 768，重叠消失且 `scrollWidth=clientWidth=1024`。
- 768px 与 390px 复验均无横向溢出；390px 下积分区与时间线隐藏，页面保持自然高度 `2448px`，主要内容和 CTA 均可访问。

### Pass 4：浏览器批注修复

- **P1**：宽屏下 `.hero-composition` 被 `1487px` 封顶，但左侧文案和右侧工作台仍继续按 viewport clamp 增长，形成约 `116px` 的潜在布局重叠；由于文案层级更高，实际表现为文字遮挡编辑器。
- **处理**：将宽屏容器扩展为 `1680px`，把 1200px 以下改为稳定堆叠，并为 1201–1279px、1280–1599px 增加安全尺寸区间。浏览器复验中，1280px 下 `hero-copy.right=404.8`、`workbench.left=452.1`，保留约 `47.3px` 间距，且 `scrollWidth=clientWidth=1280`；用户批注的 1627 × 915 视口下保留约 `85.3px` 间距。
- **P2**：主标题缺少源图中的动态高光；工作台虽然整体旋转，但外框、反射和主体仍处于近似同一平面。
- **处理**：增加仅作用于真实标题字形的循环扫光层，并在 `prefers-reduced-motion` 下显式关闭；工作台新增两层错位背板、透明镂空 rail、顶部镜面、镜面扫光、右侧立面和底部厚度层，同时保留真实 DOM/CSS 和 `preserve-3d`。
- **复验**：1280px 与宽屏均能清晰看到面板斜率、顶部半透明镜面、主面板与外框之间的空气缝、右/下错位深度；390px 继续保持单列、无横向溢出，侧面厚度自动简化。
- **审查收口**：针对 1201–1279px 的剩余外框裁切风险，再次缩小工作台上限与 near/far/side/bottom 深度偏移，确保装饰实体留在右侧净空内；新增 CSS contract 防止断点回退。

## 最终视觉保真度评估

### 1. 字体与排版

- 白色主标题与紫→蓝→青渐变标题的层级、字重、字号差和行距与源图一致。
- 眉题、正文、按钮、工作台标签和 Demo 标题保持清晰层级；移动端按视口收缩而不截断主要文案。
- 中文与数字在工作台透视状态下仍可读，没有使用烘焙文字。
- 主标题现有同步字形扫光动画，扫光不会改变可访问名称；减少动态效果模式下自动停止。

### 2. 间距与布局

- 桌面 Header、左侧 Hero Copy、右侧工作台叠压、底部卖点条和 Demo teaser 的相对位置匹配源图构图。
- 工作台最终 bounding box 与源图近似值高度一致，内部流程、预览、工具卡、时间线保持紧凑密度。
- 1024px 修复后改为无重叠堆叠；768px 与 390px 均无横向溢出，并使用自然文档高度而非固定截图画布。
- 浏览器批注复验后，1280px 紧凑桌面文案与工作台实际 bounding box 保持约 `47.3px` 间距；更宽桌面容器不再因 `1487px` 封顶产生回流遮挡。

### 3. 颜色与 tokens

- 页面以深黑蓝背景、冰蓝外壳、蓝紫边光、底部青色反射和右侧紫色反射建立与源图一致的霓虹层次。
- 标题、CTA、三类工具卡、进度、语音波形与背景音乐波形保持明确且统一的紫/蓝/青/橙语义色。
- 面板色、边框透明度、阴影和发光强度已在最终桌面截图中完成平衡，不影响文字对比度。
- 顶部蓝色镜面、双层蓝紫背板、透明镂空 rail、右侧立面和底部厚度共同建立明确的 3D 空间；这些均为无位图的装饰层。

### 4. 图像质量与资产

- 桌面和移动端浏览器检查均确认所有 `<img>` 为 `complete` 且 `naturalWidth > 0`，没有破图或失败请求。
- 内容图按真实 `<img>` 使用并保持正确裁切；没有把参考图、参考图裁片或背景截图当作 UI。
- 剩余 **P3**：剧情海报采用仓库内合规的暖色内容素材，不是源图中的冷蓝霓虹男女主场景；该差异不改变组件结构、信息层级或响应式行为。

### 5. 文案

- Header、眉题、Hero 标题、产品说明、双 CTA、流程步骤、工具卡、时间线、卖点条和 Demo teaser 均为真实文本节点。
- 文案语义覆盖 AI 出片、短剧解说、视频翻译、智能混剪、配音字幕和案例入口，与参考图表达一致。
- 交互状态文案可被辅助技术感知，工具选择、播放状态和 toast 均有明确反馈。
