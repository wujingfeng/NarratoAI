# 响应式首页 Hero 视觉还原设计

## 目标

在 `docs/web/home-hero-responsive-prototype/` 内构建一个独立的 React + Vite 单页原型，以 `docs/web/prototypes/b-style/01-home-hero-desktop.png` 为唯一视觉目标，结构化还原首页首屏 Hero 与下方 Demo teaser。原型必须保持真实 DOM、可交互、可维护，并在桌面、平板和移动端自然自适应，而不是锁定参考图的 1487 × 1058 尺寸。

## 交付边界

- 仅实现单图所覆盖的 Header、Hero 文案、CTA、AI 出片工作台、核心卖点条和 Demo teaser。
- 使用独立的 `docs/web/home-hero-responsive-prototype/` Vite 项目，不接入现有产品运行时、不改业务路由、不新增后端。
- 工作台是视觉与交互原型：不连接账号、支付、上传、生成或导出服务。
- 允许使用 `public/assets/` 中现有的七张内容图；其余图标统一使用 `@phosphor-icons/react`。

## 视觉结构

### 桌面 1487 × 1058 基准

- 页面背景以 `#02040a` 为底，叠加蓝、青、紫环境光和透视网格。
- Header 约位于 `x=51–1419, y=27–66`，包含品牌、三项导航和登录按钮。
- 左侧文案约位于 `x=60–520, y=175–618`：眉题、44–46px 白色标题、70–74px 紫蓝青渐变标题、两行说明和双 CTA。
- 工作台约位于 `x=496–1468, y=94–830`，与左文案叠压。外壳采用冰蓝、蓝紫多层发光边框，桌面基准透视接近 `perspective(1500px) rotateX(5deg) rotateY(-8deg) rotateZ(-3deg)`，底部有青色反射，右侧有紫色反射。
- 工作台内部使用 `#06101d`、`#081321` 深色面板，包含 AI 流程、9:16 视频预览、紫/蓝/橙工具卡、真实 DOM 时间线、文案块与波形。
- 核心卖点条约位于 `x=118–920, y=812–873`，四项能力以图标和细分隔线排列。
- Demo teaser 从 `y≈937` 开始露出，形成下一屏入口而不强制固定首屏高度。

## 响应式规则

- `>=1280px`：保持左右叠压、完整桌面透视、完整积分区和时间线。
- `1024–1279px`：使用较紧凑双栏，减弱旋转和外溢光效，保证工作台内容可读。
- `<1024px`：Hero 文案与工作台上下堆叠；工作台不再依赖绝对截图坐标。
- `<768px`：显示汉堡菜单；CTA 纵向排列；隐藏积分区和时间线，保留 AI 流程、视频预览和工具选择主任务。
- `390px`：水平 gutter 为 20–24px；主标题为 32–36px，渐变标题为 50–56px；使用轻透视或无破坏性透视；页面不得出现横向滚动。
- 所有区块使用 `clamp()`、Grid、Flex 和媒体查询形成自然高度，不使用固定截图画布。

## 交互与可访问性

- 产品能力与案例导航滚动到真实区块。
- 登录与开始创作触发可感知 toast；toast 自动消失并通过 `aria-live` 播报。
- 三张工具卡支持选择状态和 `aria-pressed`。
- 视频预览支持播放/暂停状态切换。
- 移动菜单支持按钮切换、ARIA 展开状态与 Escape 关闭。
- 所有可操作元素具有清晰的 `:focus-visible` 状态。
- 浮动、呼吸和旋转动画在 `prefers-reduced-motion: reduce` 下关闭。

## 反贴图约束

- 禁止在源代码中引用参考图、其裁图、reference 或 baseline 资产。
- 禁止 `data:image`、base64、canvas 截图绘制、内联手工 SVG、SVG 位图和 CSS 背景截图。
- 参考图不得进入最终页面、组件树或 `public/`。
- 文本、按钮、卡片、波形、流程、时间线、网格与发光外壳必须由真实 DOM/CSS 构建。
- `public/` 仅允许既有七张内容图片；内容图片必须使用真实 `<img>` 元素。
- 删除或隐藏参考图后，页面主体内容必须保持完整。

## 验收

- `npm test`：五项核心交互测试全部通过。
- `npm run build`：Vite 生产构建成功。
- `npm run verify:no-paste`：源代码和 `public/` 白名单检查通过。
- 浏览器在 1487 × 1058、1024 × 768、768 × 1024、390 × 844 下无横向滚动、无资源请求失败、无 console/page error。
- 1487 × 1058 同视口对比覆盖布局、比例、透视、发光、反射、卖点条和 Demo teaser；该浏览器对比完成前，`design-qa.md` 必须保持 `final result: blocked`。
