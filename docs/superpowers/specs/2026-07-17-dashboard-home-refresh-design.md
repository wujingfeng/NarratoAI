# 工作台首页内容架构改版设计

## 目标

在不改变现有「影创工坊」工作台深色紫蓝科技视觉系统、左侧导航和顶部账户操作区的前提下，重构 `/dashboard` 的主内容区，使首页同时承担活动触达、核心能力启动、辅助工具发现和创作案例灵感浏览四项职责。

## 范围

包含：

- 工作台首页主内容区的信息架构与交互重组。
- 三层内容结构：顶部双区、辅助工具区、精选作品瀑布流。
- 三项暂定工具：AI 图片、AI 视频、AI 配音。
- 现有项目缩略图与新增案例缩略图的结构化数据接入。
- 桌面及现有移动断点下的响应式降级。

不包含：

- 修改侧栏导航、顶部账户、积分余额和充值业务。
- 接入真实 AI 图片、AI 视频或 AI 配音服务。
- 改动项目创建、项目列表、旁白、翻译或混剪页面。
- 将任何用户提供的参考截图作为页面图片、背景图或位图图层。

## 视觉基线

沿用当前工作台的深黑蓝画布、深色面板、紫蓝与青色描边高光、低饱和次级文本、线性图标、细边框与克制光晕。新布局只借鉴参考图的内容分区和密度，不借鉴其品牌、色彩、卡片材质、文案或图片。

## 页面结构

### 1. 顶部双区

- **营销区域滚动横幅**：左侧宽幅活动位，展示升级、会员、创作点或季节性活动；保留关闭与分页状态，主操作沿用现有不可用提示模式。
- **主功能区**：右侧横向核心能力卡片，展示高优先级的创作入口与推荐内容。大屏与横幅同排；中小屏移动至横幅下方并保持横向滚动。

### 2. 辅助功能区

横向紧凑工具条，包含 AI 图片、AI 视频、AI 配音三个独立入口。每项展示图标、名称、简短价值说明和进入箭头；采用现有 toast 提示承接暂未开放功能，避免伪造后端状态。

### 3. 精选作品区

- 标题与轻量级分类筛选位于区块顶部。
- 下方为多列不等高的案例瀑布流，展示创作案例缩略图、标题与类型。
- 案例卡片保持真实按钮语义；点击使用现有 toast 提示，直到案例详情页具备对应路由。
- 瀑布流是独立内容模块，不嵌套在额外大卡片中；桌面端维持高密度展示，窄屏按列数递减。

## 组件与数据边界

- `DashboardPage` 只负责排列模块和共享 toast 状态。
- 顶部双区拆为营销横幅与主功能推荐条两个组件，避免将轮播状态混入页面容器。
- 工具条复用并调整现有 `ToolQuickStart` 的数据模型与视觉密度。
- 新建 `FeaturedWorks` / `FeaturedWorkCard` 管理瀑布流与单项交互。
- `dashboardData.js` 统一提供主功能、辅助工具、案例、分类数据；组件不硬编码展示内容。
- 现有侧栏、头部、账户、创建入口和 toast 组件保持接口兼容。

## 交互与状态

- 营销横幅：关闭后仅在当前会话隐藏；CTA 给出一致 toast。
- 主功能推荐：横向滚动控制或自然滚动；每个入口有键盘焦点和可读标签。
- 辅助工具与案例：hover、focus、按下反馈完整；不可用功能使用可理解的 toast。
- 分类：本地筛选案例，并有明确选中态；没有匹配项时显示空状态。
- 所有交互元素保留语义化按钮或链接，不用截图覆盖层承载交互。

## 响应式与可访问性

- 宽屏：顶部双区同排，案例 5–6 列瀑布流。
- 平板：主功能区落到横幅下方，工具条允许横向滚动，案例 3–4 列。
- 手机：沿用现有移动导航；横幅、主功能和工具条单列或横滑，案例 2 列。
- 支持键盘操作、可见焦点、图片替代文本、标题层级与 reduced-motion 偏好。

## 验收标准

1. 主页主内容严格呈现「营销区域滚动横幅 + 主功能区 + 辅助功能区 + 精选作品瀑布流」的层级关系。
2. 保留现有深色紫蓝工作台风格，未引入浅色主题或参考图的视觉语言。
3. AI 图片、AI 视频、AI 配音均为真实可点击 UI 控件，并提供暂未开放反馈。
4. 参考截图不出现在最终 DOM、CSS 背景、`data:image`、canvas 或 SVG 位图中。
5. 桌面、平板、手机视口均无横向溢出、文本遮挡或失效的主交互。
6. 既有 dashboard 验证、构建与新增结构验证通过；视觉 QA 对照所选设计方案后无 P0–P2 问题。

## 风险与决策

- 当前案例的真实详情页尚未定义，因此案例点击暂用 toast，避免新增未经确认的路由。
- 瀑布流案例需使用独立、可用的图片素材；不可使用参考截图或其裁剪内容。
- 项目当前存在与本任务无关的未提交改动；实施与提交仅纳入本设计涉及的文件。
