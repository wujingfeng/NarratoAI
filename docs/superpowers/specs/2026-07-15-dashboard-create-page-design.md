# 工作台新建创作页面设计

## 目标

在 `docs/web/homepage-prototype/` 中新增“新建创作”页面，高保真还原
`docs/web/prototypes/b-style/05-new-creation-desktop.png`，同时复用现有工作台左侧导航、右上角创作点与账户区域。

本次仅实现高保真 UI 和基础前端交互，不接入后端 API。

## 路由与入口

- 新页面路由为 `/dashboard/create`。
- 工作台首页“新建创作”主卡片跳转到该路由。
- 左侧菜单“新建创作”跳转到该路由，并显示当前选中状态。
- 移动端底部导航“新建”跳转到该路由，并显示当前选中状态。
- 工作台概览继续使用 `/dashboard`。

## 公共区域复用

创建页直接复用现有组件：

- `DashboardSidebar`
- `DashboardHeader`
- `DashboardMobileNav`
- `DashboardToast`
- `dashboardCredits`
- 工作台颜色、边框、间距和响应式 token

本次不抽取新的全局 `DashboardLayout`，避免扩大现有首页的回归范围。创建页组合既有公共组件，并将页面主体保持独立。

## 页面结构

### 页面标题

- 主标题：`创建新的 AI 视频`
- 说明：`选择创作类型并上传素材`

### 创作类型选择

提供三张可选卡片：

1. 短剧解说：加旁白讲剧情
2. 视频翻译：多语言翻译配音
3. 短剧混剪：不用懂剪辑，智能提取高光

默认选中“短剧解说”。点击卡片更新选中状态，卡片使用真实按钮、图标和文本节点实现。

不同类型的视频数量上限为：短剧解说 5 个、视频翻译 1 个、短剧混剪 10 个。当前素材数量超过目标类型上限时，阻止切换并通过 Toast 提示用户先删除多余素材；不会自动删除文件。

### 视频上传

- 支持点击文件选择器选择视频。
- 支持将视频拖拽到上传区域。
- 支持一次选择或后续追加多个文件。
- 接受 MP4、MOV、AVI 类型，单个文件大小上限按界面文案展示为 5GB。
- 文件只保存在当前页面的本地状态中，不上传服务器。
- 每行展示序号、缩略图、文件名、时长占位、本地识别状态和删除按钮。
- 用户可删除任意文件，删除后序号重新排列。
- 每个视频行均支持单独选择一个 SRT 字幕文件；未选择字幕时显示“点击上传字幕，或AI 智能识别”。
- 当浏览器无法从文件可靠获得视频时长时，使用明确的本地占位显示，不伪造后端识别结果。

初始页面保留与参考图一致的三条演示素材，以确保静态视觉验收；用户首次选择真实文件后，真实选择结果加入列表。演示素材属于页面展示数据，不表示已上传到服务器。

### 字幕上传

- 页面不设置独立字幕上传区域。
- 每个视频各自支持一个可选 `.srt` 字幕文件。
- 选择成功后在对应视频行显示文件名，再次选择可替换该视频字幕。
- 单个字幕文件大小限制按界面文案展示为 50MB。

### 创作小结

右侧摘要卡展示：

- 源视频总时长
- 预计消耗创作点
- 当前余额
- `下一步：设置参数` 按钮

初始演示数据与参考图保持一致。用户添加或删除真实文件后，摘要根据当前本地列表更新。预计消耗采用纯前端演示规则，只用于交互反馈，不代表真实计费。

点击下一步后使用 Toast 提示“参数设置功能建设中”，不创建后续路由，不发起网络请求。

### 自动保存提示

页面底部显示“系统会自动保存上传进度”。本次不实现持久化或真正的断点续传。

## 组件边界

新增组件：

- `CreatePage`：组合公共壳层、维护页面状态、处理 Toast。
- `CreationTypeSelector`：渲染创作类型并派发选择事件。
- `VideoUploadPanel`：处理文件选择和拖拽入口。
- `UploadedVideoList`：展示、排序和删除本地视频条目，并处理逐视频字幕选择。
- `CreationSummary`：展示本地摘要和下一步操作。

创建页样式放入独立的 `create.css`，避免继续扩大 `dashboard.css`。

## 状态与数据流

`CreatePage` 维护以下本地状态：

- 当前创作类型
- 视频文件列表
- 拖拽激活状态
- Toast 消息

子组件通过 props 接收数据并上报用户事件。页面不读取远端数据、不写入本地数据库，也不调用上传或计费接口。

## 响应式设计

- `1487 × 1058` 桌面视口是主要视觉验收尺寸。
- 桌面端复用固定侧栏与顶部账户区，主体由内容区和右侧摘要区组成。
- 中等宽度下，摘要区移动到主内容下方。
- `1024px` 以下沿用工作台移动结构：隐藏桌面侧栏，显示顶部品牌和底部导航。
- 窄屏中创作类型卡片、上传区和摘要卡改为单列，所有点击目标保持可操作。

## 视觉还原原则

- 参考图只用于视觉对照，不进入最终页面组件树。
- 标题、按钮、卡片、上传框、文件列表和统计数据均使用真实 DOM 和 CSS 重建。
- 视频缩略图可复用项目已有内容图片，因为其属于视频内容资产，而不是页面结构截图。
- 不使用整图或局部截图、`data:image`、base64、canvas 截图绘制、SVG 内嵌位图或 bitmap fill 伪造页面。
- 不使用参考图作为 `background-image`。
- 删除或隐藏参考图后，页面仍必须包含所有主体内容。

## 验证与验收

### 自动验证

- Vite 生产构建成功。
- `/dashboard/create` 可直接访问并显示页面标题。
- 工作台首页、桌面侧栏和移动底部导航均可进入新路由。
- 创作类型可切换。
- 文件选择、拖拽、追加和删除可更新列表。
- 三种创作类型分别限制为 5、1、10 个视频，超限时通过 Toast 阻止上传或类型切换。
- 每个视频的字幕选择与替换可工作。
- 下一步操作不发起 API 请求，并显示本地 Toast。
- 桌面和移动路由当前状态正确。

### 视觉验证

- 在 `1487 × 1058` 视口截取实现页面。
- 与参考图对照检查布局、层级、密度、间距、颜色、边框、字号和响应式行为。
- 浏览器截图只保存到 `artifacts`。

### 强制自检

1. 删除或隐藏所有参考图后，页面主体仍完整。
2. 页面不存在参考图、局部截图、base64、canvas 截图绘制或 SVG 内嵌位图。
3. 页面文本、布局、按钮、列表和交互元素均真实、可编辑、可维护。
4. 仅保留视频内容缩略图这一合理图片资产，并记录其用途。

## 非目标

- 不接入后端上传 API。
- 不实现真实字幕匹配或 AI 识别。
- 不实现真实创作点计费。
- 不实现参数设置页面。
- 不实现上传进度持久化或断点续传。
- 不重构现有工作台整体布局。
