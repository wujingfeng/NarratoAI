# 创建页视频时长与创作类型限制设计

## 目标

在 `docs/web/homepage-prototype` 的 `/dashboard/create` 页面中，为真实上传的视频自动读取本地媒体时长并更新列表与创作小结；同时将创作类型的视频数量校验从“切换时阻止”调整为“下一步时提示”。

## 范围

包含：

- 使用浏览器 `HTMLVideoElement` 和 `URL.createObjectURL` 读取上传视频的 `duration`。
- 时长成功读取后更新视频行的 `durationSeconds`、`durationLabel`，并让现有汇总计算自动刷新。
- 无法读取或时长无效时静默保留 `--:--`，不新增 Toast。
- 创作类型始终允许切换，即使当前视频数量超过目标类型上限。
- 保留上传文件时按当前创作类型 `maxVideos` 截断和提示的行为。
- 点击下一步时校验当前视频数量；超限则提示并阻止下一步。

不包含：

- 后端上传、持久化、真实计费或参数设置页面。
- 视频转码、缩略图生成或服务端媒体探测。

## 实现设计

`CreatePage` 在接受文件后先按现有流程加入本地条目，随后为每个真实 `File` 创建临时 object URL。监听 `loadedmetadata`，将有限且非负的秒数四舍五入后通过函数式 `setVideos` 更新对应条目；成功或失败都移除监听并释放 object URL。组件卸载或条目被删除时，不依赖异步结果恢复旧条目，更新前检查条目仍存在。

`handleTypeChange` 只更新 `selectedType`。`CreationSummary` 的 `onNext` 由 `CreatePage` 包装：若 `videos.length > selectedCreationType.maxVideos`，显示“当前已上传 X 个视频，类型最多支持 Y 个，请先删除多余素材”；否则保留现有“参数设置功能建设中”提示。

## 验收标准

- 选择合法视频后，视频行最终展示实际 `MM:SS` 或 `HH:MM:SS` 时长。
- 右侧源视频总时长和预计消耗随读取结果更新。
- 读取失败时无额外提示，视频行保持 `--:--`。
- 上传动作仍不会超过当前类型的最大视频数。
- 视频数超限时切换创作类型成功。
- 超限状态下点击下一步显示数量提示且不进入后续流程；删除多余视频后恢复原有下一步提示。

## 约束

- 不引入第三方媒体解析依赖。
- 不改变演示素材的初始时长数据。
- 不使用截图、base64、canvas 或参考图伪造界面。
