# 自定义编辑器实现约束

适用于本项目中视频、音频、字幕、时间轴、多轨、波形、剪辑、画布及其他自定义编辑器功能。

## 时间模型与媒体数据

- 统一使用 `x = time × pixelsPerSecond` 作为时间与横向坐标的唯一换算公式；片段、标尺、波形、播放头和点击定位共用同一时间原点。
- 点击定位基于真实编辑器内容区的边界与 `scrollLeft` 计算，不得出现标尺、素材或播放头的固定偏移。
- 项目总时长来源于实际媒体的 `loadedmetadata.duration`；时间轴、片段、波形和播放器进度上限不得依赖写死的时长。

## 布局、缩放与滚动

- 固定工具列、轨道标题列或图层列必须与可滚动编辑内容区分离；不得以叠加补丁造成固定区域可滚动或出现额外空白。
- 缩放只改变内容坐标密度、标尺步长和内容尺寸；不得改变编辑器外框、播放器宽度或页面整体宽度。
- 最小缩放比例根据可视编辑区尺寸与项目内容范围动态计算，保证默认素材完整可见；达到最小值时禁用缩小操作。
- 标尺刻度随缩放级别自适应选择合适步长（如 `1/2/5/10/30/60s`），不得固定为每秒一个刻度。
- 内容超出可视区域时，横向或纵向滚动条只能出现在编辑器内容区；编辑器外层不得产生意外溢出。
- 页面根节点设置 `overscroll-behavior-x: none`，避免横向过度滑动触发浏览器历史前进或返回。

## 交互与性能

- 选中素材、拖拽、框选和播放头更新必须局部更新；不得因点击素材重建整个编辑器、媒体元素或可视化实例。
- 使用 Pointer Events 实现拖拽与框选，并区分点击、拖拽、滚动和 seek；拖拽后按业务规则校验素材重叠与边界。
- 播放 UI 以媒体的 `play`、`pause`、`ended`、`timeupdate` 事件为准，不得仅依赖按钮点击后的本地布尔状态。
- 波形、画布或其他重型可视化实例通过稳定 `ref` 管理；仅在媒体源、素材区段或必要配置实际变化时重建或更新。

## 架构与验收

- 状态层集中管理内容范围、缩放、当前时间、选中素材与轨道/图层数据；播放器、编辑区、固定标签、可视化和属性面板职责分离。
- 交付前验证：时间零点、首个素材与播放头/画布原点对齐；最小缩放完整显示默认素材；放大后只在编辑器内部滚动；固定列不移动；点击素材不闪烁、不重建重型实例、不意外暂停播放。
