# NarratoAI C 端 Web 产品规格与页面流程

更新时间：2026-07-03

本文档用于把当前已确认的 C 端 Web 设计稿收口为开发规格。实现阶段以本文档中的「功能点 -> 设计稿」映射为准，避免页面理解错位。

## 1. 产品定位

面向想做抖音、快手等短视频账号的普通用户，提供从上传素材到生成短视频成片的 Web 创作流程。

核心目标：

- 首页一眼看到可创作的视频类型。
- 用户先选类型，再进入二级页面上传素材。
- 自动模式后台完成全流程，用户只看进度和结果。
- 精细模式按步骤让用户逐步确认。
- 配置项统一进入配置中心，不放在首页或创作首屏。
- 作品、素材、配置、失败态、空状态都有明确页面承接。

## 2. 明确不做

- 暂不考虑支付、会员、套餐、价格页。
- 首页不提供上传入口。
- 不提供 C 端用户上传自定义脚本。
- 不使用右侧常驻视频预览模块。
- 不把未被当前项目稳定支持的分析维度做成固定功能字段，例如情绪曲线、人物头像关系图等。

## 4. 全局信息架构

| 功能点 | 规格 | 设计稿 |
| --- | --- | --- |
| 顶部导航 | 首页、我的作品、素材库、配置中心、帮助。当前页使用红色下划线高亮。 | D01-D40 |
| 用户入口 | 右上角展示头像、用户名「小美」、下拉箭头。 | D01-D40 |
| 面包屑 | 任务相关页面归属到「我的作品」下；首页类型页归属到「首页」下。 | D09-D17, D34-D38 |
| 主色 | 红色用于主操作、当前状态、当前导航。绿色用于完成，蓝色用于生成中，橙色用于待确认，红色用于失败。 | D06, D09-D17, D34-D38 |
| 文案原则 | 页面只放必要字段、状态和操作，不放解释性营销文案。 | D01-D40 |

## 7. 自动模式

自动模式无需用户逐步确认，后台按类型自动完成流程，用户进入生成中页面查看状态。

| 类型 | 后台流程 | 设计稿 |
| --- | --- | --- |
| 影视解说 / 短剧解说 | 字幕处理 -> 剧情理解 -> 生成剧本 -> 生成配音 -> 合成视频 | D09 |
| 画面解说 | 画面分析 -> 生成文案 -> 剪辑脚本 -> 配音字幕 -> 合成导出 | D10 |
| 短剧混剪 | 字幕处理 -> 片段分析 -> 生成混剪脚本 -> 合成导出 | D11 |

| 功能点 | 规格 | 设计稿 |
| --- | --- | --- |
| 生成进度 | 展示当前步骤、已完成步骤、等待步骤。 | D09-D11 |
| 任务时间 | 展示已用时、预计剩余、预计完成时间。 | D09-D11 |
| 返回入口 | 可返回我的作品。 | D09-D11 |
| 取消任务 | 生成中可取消任务。 | D09-D11 |
| 完成后跳转 | 任务完成后进入成片结果或作品详情已完成页。 | D08, D35 |

## 8. 精细模式

精细模式需要用户逐步确认，每一步确认后进入下一步。

### 8.1 影视解说 / 短剧解说

| 步骤 | 功能点 | 规格 | 设计稿 |
| --- | --- | --- | --- |
| 1 | 字幕确认 | 展示字幕时间轴；支持重新识别、上传 SRT、校准时间轴、编辑字幕、逐条确认。 | D12 |
| 2 | 剧情理解 | 展示模型生成的剧情理解结果，按当前项目输出能力以 Markdown/结构化文本为主；支持重新理解、编辑、确认。 | D13 |
| 3 | 解说文案 | 展示分段解说文案；支持重新生成、调整语气、编辑单段、重写单段、确认文案。 | D14 |
| 4 | 剪辑脚本 | 展示片段、时间段、画面内容、解说文案；支持重新生成、调整节奏、编辑、上移、下移、确认脚本。 | D15 |
| 5 | 配音字幕 | 展示分段配音、字幕样式、背景音乐；每段内容需要支持独立选择配音。 | D16 |
| 6 | 合成导出 | 展示已确认内容、输出设置、开始合成视频。 | D17 |

### 8.2 画面解说

| 步骤 | 功能点 | 规格 | 设计稿 |
| --- | --- | --- | --- |
| 1 | 画面分析 | 按视频画面生成分析结果，供用户确认。 | D18 |
| 2 | 生成文案 | 基于画面分析生成解说文案，支持编辑和确认。 | D19 |
| 3 | 剪辑脚本 | 生成片段脚本，包含时间段、画面内容、解说内容。 | D20 |
| 4 | 配音字幕 | 支持配音生成、字幕样式、背景音乐设置。 | D21 |
| 5 | 合成导出 | 确认后合成成片。 | D22 |

### 8.3 短剧混剪

| 步骤 | 功能点 | 规格 | 设计稿 |
| --- | --- | --- | --- |
| 1 | 字幕确认 | 对上传或 ASR 生成的字幕进行确认。 | D23 |
| 2 | 片段分析 | 分析可混剪片段。 | D24 |
| 3 | 混剪脚本 | 生成混剪脚本，支持调整片段顺序、片段长度。 | D25 |
| 4 | 合成导出 | 合成混剪成片，不进入解说配音流程。 | D26 |

## 14. 当前项目能力与实现差异

| 功能点 | 当前判断 | 实现备注 |
| --- | --- | --- |
| SRT 可选 | 需要接入 ASR API 后成立。 | ASR 失败直接任务失败。 |
| 剧情理解展示 | 当前项目输出更接近 Markdown/文本结果。 | 不做固定人物卡、情绪曲线等强结构化 UI。 |
| 自定义上传脚本 | 不支持。 | C 端页面不出现脚本上传入口。 |
| 每段独立选择配音 | 需要新增或改造。 | 当前设计要求保留，后续实现时需要确认数据结构和合成逻辑。 |
| 作品管理 | C 端基础能力必需。 | 需要承接生成中、待确认、已完成、失败、已取消状态。 |
| 素材库管理 | C 端基础能力必需。 | 视频、字幕、背景音乐需要统一管理。 |
| 配置中心 | 需要从现有 WebUI 配置能力重组为 C 端页面。 | 配置项不放入创作首屏。 |

## 15. 后续实现建议

进入编码前建议先拆成 4 个实现阶段：

1. 页面骨架与路由：顶部导航、首页、二级上传页、我的作品、素材库、配置中心。
2. 任务状态模型：自动模式、精细模式、作品状态、失败状态、空状态。
3. 精细模式工作流：字幕确认、剧情理解、文案、脚本、配音字幕、合成导出。
4. 后端能力对接：ASR、任务持久化、素材管理、配置保存、每段独立配音。

实现前需要再次确认：本阶段是先做前端静态/半交互原型，还是直接接入真实后端流程。
