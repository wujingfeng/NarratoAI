# 视频诊断功能 - 完整功能清单

## ✅ 已实现功能

### 1. 核心诊断能力

#### 1.1 视频预处理
- [x] FFmpeg场景切换检测 (select='gt(scene,0.4)')
- [x] 镜头分割与编号
- [x] 关键帧提取 (每镜头1张代表性帧)
- [x] 视频元信息获取 (时长、分辨率、帧率)
- [x] 可调节的场景检测阈值 (0.2-0.6)

#### 1.2 五维度质量评估
- [x] **一致性检查**
  - 色调和色彩风格评估
  - 画面构图和拍摄角度协调性
  - 人物形象和服装连续性
  - VLM批量分析 (每批10帧)
  
- [x] **连贯度评估**
  - 转场自然度分析
  - 叙事逻辑连贯性
  - 节奏匹配度
  - 滑动窗口评估 (连续3镜头)
  - 时长异常检测 (<1s或>10s)
  
- [x] **重复镜头检测**
  - pHash感知哈希初筛
  - 汉明距离计算 (<5视为相似)
  - VLM语义确认 (排除相似但不同的情况)
  - 置信度评分
  
- [x] **节奏分析**
  - 镜头时长统计 (均值、标准差、最大/最小)
  - 节奏快慢判定 (过快/适中/过慢)
  - 稳定性评估
  - 异常区间识别
  - VLM主观评价
  
- [x] **废片识别**
  - FFmpeg blackdetect黑屏检测
  - FFmpeg silencedetect静音检测
  - VLM内容有效性判断
  - 删除/裁剪建议
